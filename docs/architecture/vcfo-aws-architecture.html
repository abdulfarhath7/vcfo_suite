Cost allocation across three products

How we separate VCFO from the other two AWS tools

The firm already runs three products on Amazon Web Services. They currently share a single AWS account, so Amazon issues a single invoice. That invoice does not name each product. It only lists usage (compute, storage, data transfer) for the account as a whole.

Current setup

One AWS account, one combined invoice

Tool 1, Tool 2, and VCFO Suite all draw from the same account. Finance receives one payment request from Amazon. There is no line that says “this portion is VCFO.”

What the invoice looks like today
Compute (all three tools)combined
Database (all three tools)combined
File storage (all three tools)combined
VCFO share (₹30–40k)not shown
Proposed setup

One AWS account per product

Each product is moved into its own AWS account. Amazon then issues a separate invoice for each account. VCFO’s start range of ₹30,000–40,000 appears only on the VCFO invoice.

What Finance receives after the split

How we get there

1

Open a dedicated AWS account for VCFO

Leave Tool 1 and Tool 2 where they are. Create (or assign) a third account used only for VCFO Suite, in India (Mumbai).

2

Attach a billing profile to that account

If each product should be a separate payment to Amazon, use a distinct card or billing profile per account. If one payer is preferred, costs still appear per account in AWS Cost Explorer for internal allocation.

3

Run VCFO only in that account

The website, database, file vault, and SES email for VCFO live here. The other two products stay on their accounts, so their spend cannot land on the VCFO invoice.
