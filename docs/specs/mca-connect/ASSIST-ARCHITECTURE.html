VCFO Assist Architecture

The proposed design for the extension that fills SPICe+ on the MCA portal from VCFO Suite data. This is a plan. Nothing here is built by this page, and the current code has never run on the live portal. Written 6 November 2026.

Limit: no one can promise perfect runs on a portal that can change with no notice. This design makes a problem stop the run or appear on a list, so that a wrong value does not reach a signed PDF.

Gaps in the current code

I found these by reading the code on 6 November. The field counts come from the generated field maps. An unbound field is not always a real input, because some are portal-filled or conditional.

No.Weakness found in the codeEffectFix
1Nobody has run the extension on the live portal. The offline test removes page scripts.Page rules, validation and slow lookups are untested.Fault bench, then live rungs after CS approval.
2Read-back reads the visible box only.A box can look right while the form model holds a different value.Read the form model too.
3Each field makes about 4 worker calls, plus a settle where it has a dependency.About 2,440 calls for 610 Part B fields (my count from the code, not a timing).One batch per section.
4Native events and then a jQuery event set fire on each typed field.Page rules may run twice. This is not tested.Test on the live form. Keep one event set.
5The form check looks for new semantic classes only.A changed label or option list can pass.Fingerprint the label, type and options of each bound field.
6The data covers 692 of 1,553 fields. Part A has 7 of 42 and INC-9 has 0 of 161.Most of the typing stays with a person.Sort the fields, then bind those that are real inputs.
7Part B has 50 row fields chosen by position.They could fill the wrong row, so a person fills them.Capture filled rows, then address each row by the form model.
8The binding file is in legacy/. worker.js has 694 lines. Three generations of docs exist. A dead return leg stays.Changes cost more and can go wrong.Clean base in P1.
9Optional permissions allow any https site.The extension can ask for more access than it needs.Limit to the Suite origin and localhost.
